# New game ideas (2026-11-05), checked against Roblox live search

Rule used: a lane is OPEN when no Roblox game in it has real traction (≥ 500 playing or ≥ 5M visits).
"Zero copies at all" is impossible on Roblox: about 170 searches found a copy of almost everything
(even mobile screw puzzles: Unscrew It! 801 playing).

## 1. RAGDOLL PINBALL (best)
You are the pinball. Your ragdoll avatar is launched into a giant glowing pinball machine: flippers, bumpers, ramps,
jackpot holes. Score → coins → upgrades (launch power, bounciness, magnet, multiball) → new tables. Everyone in the
server bounces in the same machine at once (multiball chaos).
- Gap: every pinball game on Roblox is dead (Launch a Pinball! 8 playing / 14k visits; Brainrot PinBall 0 / 457k;
  Bumperworks 0 / 33k). No ragdoll pinball at all.
- Proven parts: pinball (Space Cadet, Pinball FX), the ragdoll wave, the launch-upgrade loop.
- Risk: the ragdoll trend may cool by spring; physics must feel good (jank is fine, it's the comedy).
- Study for the build: 3D Pinball Space Cadet + Pinball FX tables, the top Roblox ragdoll games for feel, Launch Your
  CAR for the upgrade loop.

## 2. THE 1,000,000-LAYER PRESENT (Christmas; best as a Find the Glowing Box event)
A giant gift. Rip wrapping-paper layers (ASMR), surprises in every layer, the prize in the core. Same engine as
Find the Glowing Box (layers instead of blocks).
- Gap: Unwrap A Gift 22 playing / 16k visits, Open A Gift 3 / 11k.
- Smart play: ship it as the December update of Find the Glowing Box, not a new game (80% code reuse, keeps players).
- Risk: seasonal, dies in January as a standalone game.
